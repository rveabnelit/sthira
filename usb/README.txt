STHIRA — автономная версия для показа (Windows)

КАК ЗАПУСТИТЬ
1. Скопируйте папку STHIRA на флешку или компьютер целиком.
2. Откройте STHIRA.bat (двойной клик).
3. Через несколько секунд браузер откроется сам на адресе http://127.0.0.1:3100
   Если не открылся — наберите этот адрес в браузере вручную.
4. Чтобы остановить — закройте чёрное окно консоли или нажмите Ctrl+C.

Интернет НЕ нужен: все страницы, шрифты, изображения и база лежат внутри папки.

ВХОД
  Ученик:        student@sthira.school / Student12345!
  Другой ученик: new@sthira.school     / Student12345!
  Администратор: admin@sthira.school   / Admin12345!
Можно также зарегистрировать новый аккаунт прямо на сайте.

ЧТО ПОКАЗАТЬ
  /                 — публичный сайт
  /practice         — каталог практик
  /programs         — программы
  /pricing          — тарифы
  /app              — личный кабинет ученика (после входа)
  /app/guide        — STHIRA Guide
  /admin            — админ-панель (после входа администратором)

ВАЖНО
- Это демонстрационная версия: оплата проходит в тестовом режиме, реальные деньги
  не списываются; видео — демо-плеер; AI-наставник работает офлайн по базе знаний.
- Данные (прогресс, аккаунты) сохраняются в app\data\sthira.db на носителе.
  Хотите начать с чистого листа — удалите эту папку data, она создастся заново.
- Если порт 3100 занят, программа автоматически выберет следующий свободный
  и напишет адрес в консоли.
- Антивирус или SmartScreen может спросить разрешение для node.exe — это
  официальный runtime Node.js, разрешите запуск.
- Не извлекайте флешку во время работы: база данных открыта.

СОСТАВ
  STHIRA.bat        — запуск
  node\node.exe     — Node.js runtime (Windows x64)
  app\              — собранное приложение, база и ассеты
  app\launcher.js   — выбор свободного порта и открытие браузера

Если нужна версия для macOS или Linux — скажите, соберу отдельно.
