# Дизайн-система STHIRA

Дизайн собран как единая система: публичный сайт, личный кабинет, наставник и админ-панель используют
одни токены, компоненты и принципы композиции.

## 1. Визуальное направление

Премиальный редакционный минимализм: тёплая бумажная палитра, крупная антиква в заголовках,
сдержанный интерфейсный sans-serif, тонкие линии вместо теней, много воздуха. Никаких эзотерических
клише, неона, агрессивных градиентов и перегруженной анимации.

## 2. Токены

| Токен | Значение | Использование |
|---|---|---|
| `--color-ivory` | `#F3F0E8` | основной фон |
| `--color-paper` | `#FBFAF7` | карточки, поверхности |
| `--color-sage` | `#A4AD96` | вторичный акцент, прогресс |
| `--color-forest` | `#24392F` | основные кнопки, тёмные секции |
| `--color-sand` | `#D8C9B5` | декоративные обложки, бейджи |
| `--color-ink` | `#292B27` | основной текст |
| `--color-muted` | `#85877F` | вторичный текст |
| `--color-line` | `#E4E0D7` | границы и разделители |

Дополнительно: `sage-soft`, `sand-soft`, `clay`, `success`, `warning`, `danger` — для состояний и
обложек. Радиусы: 12–20 px (карточки 18 px, кнопки 12 px, обложки 18–24 px). Тени используются только
для «парящих» элементов (рекомендация на главной, модальные панели).

## 3. Типографика

- **Display:** Cormorant Garamond 500/600 (self-hosted, кириллица). Заголовки `display-1`…`display-4`,
  плотный интерлиньяж 0.99–1.12, отрицательный трекинг.
- **UI/текст:** Inter 400/500/600. Основной текст 13–16 px, line-height 1.6–1.75.
- **Микро-лейблы:** 10–11 px, uppercase, трекинг 0.14–0.18em.
- Все шрифты подключены локально (`@fontsource`) — без внешних запросов.

## 4. Базовые компоненты

`src/components/ui`: кнопки (primary/secondary/soft/ghost/danger, размеры sm/md/lg), поля и селекты,
бейджи, прогресс, аватары, статистика, пустые состояния, скелетоны, тосты, офлайн-баннер.

`src/components/cards`: карточка практики, карточка программы, карточка эфира, строка истории, отзыв,
кнопка избранного.

`src/components/covers/practice-cover.tsx` — типографическая обложка: тональная палитра, тонкая
геометрия (арка/круг/линия) и номер практики. Заменяет стоковые фотографии и сохраняет единство
каталога; при желании администратор указывает реальную обложку URL-ом.

`src/components/site`: шапка с мобильным меню, подвал, заголовок страницы, аккордеон FAQ, фильтры
каталога, блок тарифов, превью Guide, юридический шаблон.

`src/components/app`: оболочка кабинета (сайдбар, верхняя строка, мобильная нижняя навигация),
календарь активности и недельные бары.

`src/components/admin`: оболочка админки, таблицы, заголовки, графики (area/bar/donut).

## 5. Сетка и адаптивность

- Контейнер до 1320 px, боковые отступы 20/32/48 px.
- Контрольные ширины: 1440, 1280, 768, 390. Проверено отсутствие горизонтальной прокрутки
  (см. `scripts/visual-check.mjs`).
- Каталог: 4 колонки на 1440, 3 на 1280 и планшете, 2 на мобильном.
- Таблицы админки на мобильных превращаются в карточки.
- Мобильная навигация кабинета — фиксированная нижняя панель; публичного сайта — полноэкранное меню.

## 6. Состояния

Для каждого сценария предусмотрены: загрузка (скелетоны), пустое состояние с конкретным действием,
ошибка с возможностью повторить, успех, недоступность по тарифу, отсутствие подписки, отсутствие
интернета, 404 и техническая ошибка.

## 7. Доступность

- Видимый фокус (`:focus-visible`) с контрастным контуром.
- Ссылка «К содержанию», семантические `header/nav/main/footer`, `aria-current` в навигации.
- Подписи полей, `aria-invalid`, тексты ошибок рядом с полями.
- Контраст текста на тёплом фоне проверен (основной текст `#292B27` на `#F3F0E8` — более 12:1).
- Управление плеером с клавиатуры (пробел, стрелки), подписи кнопок.
- Уважение `prefers-reduced-motion`.
